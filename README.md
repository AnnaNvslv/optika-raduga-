# Оптика «Радуга» — сайт

Одностраничный сайт районной оптики в Санкт-Петербурге (пр. Стачек, 72,
рядом с метро «Кировский завод»). Собран с нуля на Astro — из старого
сайта на Tilda использованы только тексты, контакты и логотип, без разметки,
стилей и скриптов площадки.

## Стек

- [Astro](https://astro.build) (статическая генерация, без SPA)
- TypeScript
- Обычный CSS (без UI-фреймворков), минимум клиентского JS
- Русский шрифт PT Sans (кириллица) — встроен в CSS как data URI, без
  подключения Google Fonts или любого другого внешнего CDN

## Разработка

```bash
npm install
npm run dev       # локальный сервер разработки
npm run build     # production-сборка в dist/
npm run preview   # предпросмотр собранной версии
```

## Структура

```text
src/
  components/   переиспользуемые блоки (Header, Hero, FAQ, Contacts, ...)
  data/         все изменяемые данные: контакты, услуги, FAQ, акции,
                сотрудники, режим работы — редактируются отдельно от вёрстки
  layouts/      общий каркас страницы (SEO-теги, Schema.org)
  pages/        index.astro — единственная страница сайта
  styles/       глобальные стили и шрифт
  assets/       логотип/favicon в виде data URI (см. ниже, почему)
public/
  robots.txt, sitemap.xml
```

## Как редактировать контент

Почти всё, что может поменяться, вынесено в `src/data/*.ts`:

- `contacts.ts` — телефоны, адрес, часы работы, соцсети, ссылка «Как пройти»
- `services.ts` — карточки услуг
- `steps.ts` — шаги «Как заказать очки»
- `trust.ts` — блок доверия
- `faq.ts` — частые вопросы и ответы
- `offers.ts` — блок «Актуальные предложения» (скрыт, пока нет ни одной
  акции с `active: true`)
- `team.ts` — блок «Наша команда» (скрыт, пока массив пуст)

Список фактов, которые нужно подтвердить или обновить, — в
[`CONTENT_TO_CONFIRM.md`](./CONTENT_TO_CONFIRM.md).

## Изображения: почему всё внутри кода

В этой среде разработки автоматическая запись файлов в GitHub
передаёт содержимое как текст, из-за чего настоящие бинарные файлы
(PNG/WebP/шрифты) повреждаются при загрузке через доступный
инструмент. Поэтому:

- логотип и favicon (маленькие, уже оптимизированные) встроены как
  base64 data URI в `src/assets/images.ts` — работает полностью
  автоматически, без ручных шагов;
- шрифт PT Sans аналогично встроен в `src/styles/fonts.css`;
- OG-изображение для превью в соцсетях подготовлено (`og-cover.png`,
  отправлено отдельным файлом) и требует одной ручной
  загрузки в `public/` через веб-интерфейс GitHub — подробности в
  `CONTENT_TO_CONFIRM.md`, пункт 14.

Фотографий помещения/сотрудников в переданных материалах не было —
сайт сознательно спроектирован без стоковых фото, с акцентом на
типографику, цвет и простые собственные иконки.

## Публикация

Сайт публикуется на GitHub Pages через GitHub Actions
(`.github/workflows/deploy.yml`) при пуше в `main`. Домен
`оптикарадуга.рф` в метаданных уже прописан, но DNS и `CNAME` **не
подключены** — это осознанно оставлено на отдельное подтверждение владельца.
