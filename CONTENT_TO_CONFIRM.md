# Что нужно подтвердить

Сайт полностью собран и работает с безопасными формулировками там, где
факт не подтверждён. Ничего из этого списка не блокирует публикацию —
все данные централизованы в `src/data/`, поменять их — дело одной правки.

## 0. Фотографии для загрузки — сделать первым делом
В чате отправлены 6 файлов (`hero.webp`, `promo-banner.webp`,
`avatar-kid.webp`, `avatar-young.webp`, `avatar-mid.webp`,
`avatar-senior.webp`). Их нужно залить в `public/images/` точно так же,
как раньше og-cover.png (см. пункт 14): в GitHub — Add file → Upload
files → перетащить все 6 файлов в `public/images/` → Commit. Без этого
шага хиро-фото, баннер акций и аватары в блоке доверия будут показывать
сломанную картинку вместо фото.

Важно: это стоковые/иллюстративные фото, а не реальный магазин или
сотрудники — они временны и ничего конкретного не утверждают. Как только
появятся реальные фото витрины/интерьера/мастеров — замените файлы в
GitHub под теми же именами (новая загрузка с тем же именем автоматически
перекроет старый файл) — код менять не надо. Это даст сайту больше
доверия, чем любые другие правки в этом списке.

## 9. Состав сотрудников
Старый список сотрудников **не перенесён** — он устарел (там числится
