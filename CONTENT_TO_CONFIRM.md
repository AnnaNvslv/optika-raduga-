## 14. OG-изображение (превью для соцсетей и мессенджеров)
Готовое брендированное изображение 1200×630 (`og-cover.png`, отправлено
вам отдельным файлом) нужно вручную положить в `public/og-cover.png`
репозитория. **Почему не сделано автоматически:** инструмент, которым в
этой сессии можно писать файлы в GitHub, передаёт содержимое как текст,
из-за чего бинарные файлы (PNG/JPG) повреждаются при загрузке — это
подтверждено тестом на самом репозитории. Все изображения, которые обязаны
*быть* отдельным файлом (лого и favicon эту проблему обошли, встроившись как
data-URI прямо в код), для OG-картинки такой обходной путь не работает
— Facebook/VK/Telegram запрашивают файл по прямой ссылке, а не встроенную строку.
**Как добавить:** в GitHub — Add file → Upload files → перетащить
`og-cover.png` в корень `public/` → Commit. После этого превью ссылки
в мессенджерах и соцсетях заработает.
